# 国际化方案

## 依赖

- `flutter_localizations`（SDK）
- `intl`

## 配置

### pubspec.yaml

```yaml
flutter:
  generate: true
```

### l10n.yaml

```yaml
arb-dir: l10n
template-arb-file: app_en.arb
output-localization-file: app_localizations.dart
```

## ARB 文件

| 文件 | 语言 |
|------|------|
| `l10n/app_en.arb` | 英文（模板） |
| `l10n/app_zh.arb` | 中文 |
| `l10n/app_ja.arb` | 日语 |

### 示例条目

```json
// app_en.arb
{
  "@@locale": "en",
  "appTitle": "Astra",
  "navHome": "Home",
  "navTodos": "Todos",
  "navSettings": "Settings",
  "themeLight": "Light",
  "themeDark": "Dark",
  "themeSystem": "Auto"
}
```

## Locale 状态管理

```dart
@riverpod
class LocaleNotifier extends _$LocaleNotifier {
  @override
  Future<Locale?> build() async {
    final prefs = await SharedPreferences.getInstance();
    final code = prefs.getString('app_locale');
    if (code == null) return null; // 跟随系统
    return Locale(code);
  }

  Future<void> setLocale(String languageCode) async { ... }
}
```

## MaterialApp 绑定

```dart
MaterialApp(
  localizationsDelegates: AppLocalizations.localizationsDelegates,
  supportedLocales: AppLocalizations.supportedLocales,
  locale: ref.watch(localeProvider).value, // null = 系统默认
)
```

## 持久化

| 键 | 值 | 说明 |
|----|-----|------|
| `app_locale` | `zh` / `en` / `ja` | 用户选择的语言 |

## 使用方式

```dart
final l10n = AppLocalizations.of(context)!;
Text(l10n.navHome);
```

## 回退策略

- `locale` 为 `null` 时跟随系统
- 系统语言不在 `zh`/`en`/`ja` 时，Flutter 回退到 `supportedLocales` 第一项（英文）
