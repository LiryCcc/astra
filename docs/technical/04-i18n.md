# 国际化方案

文案以 **纯 Dart 代码** 管理，放在 `lib/i18n/`，不使用 JSON、YAML、ARB 或 `flutter gen-l10n`。

## 文件结构

```
lib/i18n/
├── schema.dart    # 文案表定义（key 与类型契约）
├── zh_cn.dart     # 简体中文
├── en.dart        # 英文
└── jp.dart        # 日语
```

| 文件 | 职责 |
|------|------|
| `schema.dart` | 定义 `I18nSchema` 抽象类或文案表结构，约束所有语言文件 |
| `zh_cn.dart` | 简体中文 `I18nSchema` 实现 |
| `en.dart` | 英文 `I18nSchema` 实现 |
| `jp.dart` | 日语 `I18nSchema` 实现 |

## schema.dart — 文案表

```dart
abstract class I18nSchema {
  String get appTitle;
  String get navHome;
  String get navTodos;
  String get navSettings;
  String get themeLight;
  String get themeDark;
  String get themeSystem;
  // 新增文案在此声明
}
```

## 语言实现

```dart
// en.dart
import 'schema.dart';

class EnI18n implements I18nSchema {
  @override
  String get appTitle => 'Astra';

  @override
  String get navHome => 'Home';

  @override
  String get navTodos => 'Todos';

  @override
  String get navSettings => 'Settings';

  @override
  String get themeLight => 'Light';

  @override
  String get themeDark => 'Dark';

  @override
  String get themeSystem => 'Auto';
}
```

`zh_cn.dart`、`jp.dart` 结构相同，仅字符串值不同。

## 与 store 集成

语言偏好由 `store/locale_store.dart` 管理（持久化到 `shared_preferences`）。

```dart
// store/i18n_provider.dart（或合入 locale_store.dart）
import 'package:flutter_riverpod/flutter_riverpod.dart';

import '../i18n/en.dart';
import '../i18n/jp.dart';
import '../i18n/schema.dart';
import '../i18n/zh_cn.dart';
import 'locale_store.dart';

final i18nProvider = Provider<I18nSchema>((ref) {
  final locale = ref.watch(localeStoreProvider);
  switch (locale) {
    case AppLocale.zhCn:
      return ZhCnI18n();
    case AppLocale.en:
      return EnI18n();
    case AppLocale.jp:
      return JpI18n();
  }
});
```

## MaterialApp 绑定

```dart
MaterialApp(
  locale: ref.watch(localeStoreProvider).toLocale(),
  supportedLocales: const [
    Locale('zh', 'CN'),
    Locale('en'),
    Locale('ja'),
  ],
  // 不使用 AppLocalizations；文案通过 i18nProvider 获取
)
```

## 使用方式

```dart
final strings = ref.watch(i18nProvider);
Text(strings.navHome);
```

## 持久化

| 键 | 值 | 说明 |
|----|-----|------|
| `app_locale` | `zh_cn` / `en` / `jp` | 用户选择的语言 |

## 新增文案流程

1. 在 `schema.dart` 增加 getter / 字段
2. 在 `zh_cn.dart`、`en.dart`、`jp.dart` 同步实现
3. 页面通过 `ref.watch(i18nProvider)` 使用，禁止硬编码字符串

## 回退策略

- 未设置语言时跟随系统
- 系统语言不在支持列表时回退到 `en.dart`

## 禁止事项

- 不使用 `l10n/` 目录、`l10n.yaml`、`*.arb`
- 不使用 `flutter_localizations` 的 codegen 文案
- `i18n/` 不得 import `store/`、`pages/` 等上层目录
