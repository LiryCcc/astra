# 平台与设备

## 目标平台

| 类别   | 平台    | 设备形态       |
| ------ | ------- | -------------- |
| 移动端 | Android | 手机、平板     |
| 移动端 | iOS     | iPhone、iPad   |
| 桌面端 | Windows | 笔记本、台式机 |
| 桌面端 | macOS   | MacBook、iMac  |

## 最低版本建议

| 平台    | 最低版本               |
| ------- | ---------------------- |
| Android | API 33（Android 13.0） |
| iOS     | iOS 18                 |
| Windows | Windows 10             |
| macOS   | macOS 12.0             |

## 设备形态定义

| 形态 | 典型场景         | 输入方式       |
| ---- | ---------------- | -------------- |
| 手机 | 竖屏为主，窄屏   | 触控           |
| 平板 | 横竖屏，中等宽度 | 触控、可选键盘 |
| 桌面 | 宽屏窗口         | 鼠标、键盘     |

## 非目标平台（首版）

- Web
- Linux
- watchOS / tvOS

如需后续扩展，应不影响现有四端架构设计。
