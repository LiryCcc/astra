# 项目概述

## 目标

构建一款跨平台 Flutter 应用，同一套代码运行于 **Android、iOS、Windows、macOS**，并适配 **手机、平板、桌面** 三种设备形态。

## 核心能力

- **三个页面路由**：首页、设置页、TodoMVC 页
- **Material Design 3** 风格
- **主题**：日间、夜间、跟随系统自动切换
- **语言**：中文、英文、日语，可切换并持久化

## 范围说明

- 本文档集仅描述需求、技术方案与实施计划
- Flutter SDK 的安装由开发者自行完成，不在本阶段范围内
- 首版以功能完整、体验一致为优先，不包含账号体系、云同步等扩展能力

## 应用命名

- 仓库名：`astra`
- 应用显示名：默认使用「Astra」（可在 [待确认项](13-open-questions.md) 中调整）
