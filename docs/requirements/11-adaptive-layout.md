# 多端适配

本文档定义手机、平板、桌面三种设备形态下的布局、导航与交互适配需求。

## 适配目标

同一套 Flutter 代码，在四种平台（Android、iOS、Windows、macOS）上提供 **一致的功能** 与 **符合设备习惯的布局**。

## 屏幕断点

| 类型 | 宽度范围 | 典型设备 |
|------|----------|----------|
| 手机（compact） | < 600 dp | iPhone、Android 手机 |
| 平板（medium） | 600 dp – 1199 dp | iPad、Android 平板、小窗桌面 |
| 桌面（expanded） | ≥ 1200 dp | Windows/macOS 全屏窗口、大显示器 |

> 断点为逻辑像素（dp），基于 `MediaQuery.sizeOf(context).width` 判断。

## 导航适配

| 断点 | 导航组件 | 说明 |
|------|----------|------|
| 手机 | `BottomNavigationBar` | 3 个 Tab，底部固定，带图标 + 文字标签 |
| 平板 | `NavigationRail` | 左侧窄栏，图标 + 可选文字标签 |
| 桌面 | `NavigationRail` | 左侧栏可显示展开标签；窗口极宽时可评估 `NavigationDrawer` |

### 导航行为

- 断点变化时（如旋转、窗口缩放）自动切换导航形态，无需重启
- 切换导航形态时保持当前路由不变
- 导航区域不挤压内容区至不可读（Rail 宽度建议 72–80 dp）

## 内容区布局

### 通用原则

- 使用 `SafeArea` 避开刘海、状态栏、系统手势区
- 内容区与导航区分离，由 `AdaptiveScaffold` 统一管理
- 宽屏下内容 **居中 + 最大宽度限制**，避免单行过长难以阅读

### 各页最大内容宽度建议

| 页面 | 手机 | 平板 | 桌面 |
|------|------|------|------|
| 首页 | 全宽 - padding | 全宽 - padding，卡片 2 列 | 最大 960 dp，卡片 2–3 列 |
| 设置页 | 全宽列表 | 最大 600 dp 居中 | 最大 720 dp 居中 |
| Todo 页 | 全宽 | 最大 720 dp 居中 | 最大 800 dp 居中 |

### 首页布局

| 断点 | 布局 |
|------|------|
| 手机 | 欢迎区 → 统计卡片（纵向）→ 快捷入口（纵向） |
| 平板 | 统计卡片横向 2 列；快捷入口可 2 列网格 |
| 桌面 | 统计与入口可多列；整体水平居中 |

### 设置页布局

| 断点 | 布局 |
|------|------|
| 手机 | 全宽 `ListView`，分组标题 + 列表项 |
| 平板/桌面 | 列表限制最大宽度并水平居中 |

### Todo 页布局

| 断点 | 布局 |
|------|------|
| 手机 | 输入框全宽；过滤按钮可横向滚动或换行 |
| 平板 | 输入区与列表同宽居中；过滤栏单行展示 |
| 桌面 | 同平板；列表项 hover 态（鼠标悬停高亮） |

## 横竖屏

| 平台 | 要求 |
|------|------|
| 手机 | 竖屏为主；横屏时布局仍可用，不崩溃、不严重错位 |
| 平板 | 横竖屏均正常适配；横屏时倾向 medium/expanded 布局 |
| 桌面 | 窗口自由缩放，断点随宽度实时变化 |

## 输入方式适配

| 输入方式 | 适配要求 |
|----------|----------|
| 触控 | 点击区域 ≥ 48×48 dp；列表项间距足够 |
| 鼠标 | 桌面端按钮/列表项有 hover 反馈；光标为 pointer |
| 键盘 | Todo 输入框支持 Enter 提交；桌面端支持 Tab 焦点切换（基础） |

## 平台特定适配

### Android

- 支持不同屏幕密度（mdpi–xxxhdpi）
- 平板（sw600dp+）走 medium 断点逻辑
- 全面屏、手势导航条区域使用 `SafeArea`

### iOS

- iPhone 刘海 / Dynamic Island 区域适配
- iPad 分屏、Slide Over 时按实际宽度走断点，不假定全屏
- iPad 横屏时优先 NavigationRail

### Windows

- 窗口默认尺寸建议 1280×720 或以上
- 支持窗口最小尺寸（建议不小于 400×600），缩小至手机断点时切换为 BottomBar
- 高 DPI 缩放下文字与图标清晰

### macOS

- 窗口可缩放，断点随宽度变化
- 预留顶部标题栏/工具栏区域
- 菜单栏为系统级，首版不要求自定义应用菜单

## 字体与密度

- 不手动写死字体大小；使用 `Theme.of(context).textTheme`
- 系统字体缩放（无障碍文字大小）下，布局允许滚动，不截断关键操作
- 平板/桌面不单纯等比放大手机 UI，应利用额外空间（多列、更宽留白）

## 性能与体验

- 断点切换时避免整页重建闪烁
- 列表页（Todo）在长列表下保持滚动流畅
- 旋转/缩放窗口时状态（输入内容、滚动位置）尽量保持

## 验收要点（多端）

- [ ] 手机竖屏：底部导航，三页布局正常
- [ ] 平板横屏：左侧 Rail，内容居中
- [ ] 桌面宽窗口：Rail + 限宽内容区
- [ ] 缩小桌面窗口至 < 600 dp：自动切换为底部导航
- [ ] iPad 分屏窄窗：按实际宽度选择布局，不崩溃
- [ ] 横竖屏旋转后：当前页面与数据保持
