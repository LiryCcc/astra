# 全局导航

## 导航目标

三个一级页面之间可快速切换，用户始终清楚当前所在页面。

## 导航项

| 标签（本地化） | 路由        | 图标建议    |
| -------------- | ----------- | ----------- |
| 首页           | `/`         | `home`      |
| Todo           | `/todos`    | `checklist` |
| 设置           | `/settings` | `settings`  |

## 导航形态（按设备）

| 设备 | 导航组件                               | 位置         |
| ---- | -------------------------------------- | ------------ |
| 手机 | `BottomNavigationBar`                  | 底部         |
| 平板 | `NavigationRail`                       | 左侧（窄栏） |
| 桌面 | `NavigationRail` 或 `NavigationDrawer` | 左侧         |

具体断点与切换规则见 [多端适配](11-adaptive-layout.md)。

## 行为要求

- 当前路由对应导航项高亮
- 点击导航项切换到对应页面
- 切换时保持各页面状态（Todo 列表、滚动位置等，首版至少保持 Todo 数据）
- 手机端底部导航不遮挡主要内容（配合 `SafeArea`）

## 非需求

- 首版不要求深层链接（Deep Link）配置
- 首版不要求 Web URL 路由
