# 设置页

路由：`/settings`

## 功能描述

集中管理应用偏好：主题与语言。

## 设置项

### 1. 主题

- 选项：日间 / 夜间 / 自动
- 单选，互斥
- 切换立即生效并持久化

### 2. 语言

- 选项：中文 / English / 日本語
- 单选，互斥
- 切换立即生效并持久化

## 布局要求

| 设备 | 布局 |
|------|------|
| 手机 | 全宽列表，分组标题 + `ListTile` |
| 平板 | 内容区居中，最大宽度约 600–720dp |
| 桌面 | 同平板，可左侧导航 + 右侧设置内容 |

## 交互

- 使用 `RadioListTile` 或等效组件，当前选中项有明确视觉反馈
- 无需「保存」按钮，每次选择自动写入本地存储

## 持久化

- 主题选择重启后保持
- 语言选择重启后保持
