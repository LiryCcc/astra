# 首页

路由：`/`

## 功能描述

应用入口页，提供概览信息与快捷导航。

## 内容区块

### 1. 欢迎区

- 应用名称（Astra）
- 简短介绍文案（一句话说明应用用途）

### 2. 待办统计

从 Todo 数据实时派生，展示：

- 待办总数
- 未完成数量

数据为空时显示 0，不报错。

### 3. 快捷入口

- 跳转到 Todo 页
- 跳转到设置页

### 4. 状态展示（可选）

- 当前主题模式（日间/夜间/自动）
- 当前语言（中文/English/日本語）

## 布局要求

| 设备 | 布局 |
|------|------|
| 手机 | 纵向堆叠，统计与入口为卡片 |
| 平板 | 统计卡片可横向并排（2 列） |
| 桌面 | 内容居中，最大宽度限制（如 960dp），卡片可多列排列 |

详见 [多端适配](11-adaptive-layout.md)。

## 交互

- 点击快捷入口跳转对应路由
- 无编辑类操作，只读展示为主
