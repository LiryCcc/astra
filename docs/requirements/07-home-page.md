# 首页

路由：`/`

## 功能描述

应用入口页，仅展示品牌标识与版本信息。

## 内容区块

页面仅包含以下三项，居中显示：

| 元素 | 说明 |
|------|------|
| Logo | 应用图标 |
| 应用名称 | Astra |
| 版本号 | `1.0.0`（初始版本） |

## 版本号

- 初始版本：**1.0.0**
- 版本号定义在 `pubspec.yaml` 的 `version` 字段，首页通过 `package_info_plus` 或读取 `pubspec` 版本展示
- 显示格式：`v1.0.0` 或 `1.0.0`（实施时统一一种格式）

## 布局要求

| 设备 | 布局 |
|------|------|
| 手机 | Logo、名称、版本号纵向居中排列 |
| 平板 | 同手机，整体垂直水平居中 |
| 桌面 | 同手机，整体垂直水平居中 |

详见 [多端适配](11-adaptive-layout.md)。

## 交互

- 纯展示页，无按钮、无跳转、无编辑操作
- 页面切换通过全局导航完成
