# 路由与页面

应用包含 **3 个一级路由**，通过全局导航切换。

## 路由表

| 路由 | 页面 | 说明 |
|------|------|------|
| `/` | 首页 | 应用 Logo、名称与版本号 |
| `/settings` | 设置页 | 主题、语言、关于等 |
| `/todos` | TodoMVC 页 | 经典 Todo 增删改查、过滤、持久化 |

## 路由行为

- 应用启动默认进入 `/`（首页）
- 三个路由均为顶级页面，平级切换，无嵌套子路由（首版）
- 当前路由在导航组件中高亮显示
- 支持通过导航栏点击切换，不要求浏览器式前进/后退（移动端可选支持系统返回）
