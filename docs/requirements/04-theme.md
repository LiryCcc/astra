# 主题模式

## 支持的模式

| 模式 | 用户可见名称（中/英/日） | 行为 |
|------|--------------------------|------|
| 日间 | 日间 / Light / ライト | 始终使用浅色主题 |
| 夜间 | 夜间 / Dark / ダーク | 始终使用深色主题 |
| 自动 | 自动 / Auto / 自動 | 跟随操作系统浅色/深色设置 |

## 交互要求

- 在设置页提供三种模式的单选切换
- 切换后 **立即生效**，无需重启应用
- 用户选择 **持久化到本地**，下次启动恢复上次选择

## 视觉要求

- 基于 Material Design 3
- 浅色与深色主题均应保证文字对比度可读
- 组件（按钮、卡片、输入框、导航栏等）在两套主题下风格一致
- 使用统一品牌色（seed color），自动生成 `ColorScheme`

## 与系统的关系

- 「自动」模式下，系统切换浅色/深色时，应用应同步切换
- 应用内主题选择不影响系统设置，仅影响本应用
