# TodoMVC 页

路由：`/todos`

参考 [TodoMVC](https://todomvc.com/) 核心交互，实现经典待办管理能力。

## 核心功能

| 功能 | 说明 |
|------|------|
| 新增 | 输入框 + 添加按钮；支持回车提交 |
| 列表展示 | 展示所有 Todo 项 |
| 完成切换 | 勾选/取消勾选切换完成状态 |
| 编辑 | 修改 Todo 标题（双击或编辑按钮进入编辑态） |
| 删除 | 删除单条 Todo |
| 过滤 | All（全部）/ Active（未完成）/ Completed（已完成） |
| 标记全部完成 | 一键将所有未完成项标为完成 |
| 清除已完成 | 删除所有已完成项 |
| 计数 | 显示剩余未完成数量 |
| 持久化 | 本地存储，应用重启后数据不丢失 |

## 空状态

- 无 Todo 时显示友好提示文案与引导（如「添加你的第一条待办」）
- 过滤结果为空时显示对应提示（如「没有已完成的待办」）

## 输入校验

- 不允许添加空白标题
- 编辑时不允许保存为空

## 布局要求

| 设备 | 布局 |
|------|------|
| 手机 | 顶部输入区 + 过滤栏 + 纵向列表 |
| 平板 | 输入区与列表可更宽，过滤栏横向排列 |
| 桌面 | 内容居中限宽（如 600–800dp），输入框与列表同列 |

详见 [多端适配](11-adaptive-layout.md)。

## 可选增强（非必须）

- 滑动删除（移动端）
- 空状态插画
- 拖拽排序

首版不强制包含以上增强项。
