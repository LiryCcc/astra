# 验收标准

## 平台编译与运行

- [ ] Android 可编译运行
- [ ] iOS 可编译运行
- [ ] Windows 可编译运行
- [ ] macOS 可编译运行

## 路由与导航

- [ ] 三个路由（`/`、`/settings`、`/todos`）均可访问
- [ ] 导航栏当前页高亮正确
- [ ] 页面切换后状态合理保持（尤其 Todo 数据）

## 主题

- [ ] 日间模式显示浅色主题
- [ ] 夜间模式显示深色主题
- [ ] 自动模式跟随系统切换
- [ ] 主题选择重启后保持

## 国际化

- [ ] 中文界面文案完整
- [ ] 英文界面文案完整
- [ ] 日语界面文案完整
- [ ] 语言切换即时生效且重启后保持

## TodoMVC

- [ ] 新增、完成、编辑、删除
- [ ] 过滤（All / Active / Completed）
- [ ] 标记全部完成、清除已完成
- [ ] 未完成计数正确
- [ ] 数据本地持久化，重启不丢失

## 多端适配

- [ ] 手机（< 600 dp）：底部导航，布局正常
- [ ] 平板（600–1199 dp）：左侧 NavigationRail，内容居中
- [ ] 桌面（≥ 1200 dp）：Rail + 限宽内容区
- [ ] 窗口缩放/旋转后断点切换正确
- [ ] 触控与鼠标操作均可用

## UI 质量

- [ ] Material 3 风格统一
- [ ] 浅色/深色主题下均可读
